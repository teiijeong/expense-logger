# Expense Logger

## Motivation
I built this script to automate my expense tracking process.

I currently use an expense tracker template on Google Spreadsheets and log my expenses manually. I have to log into all three of my banking apps, go through each individual transaction on my credit/debit cards, record the transaction amount and categorize it one by one. Because this is tedious and takes up time, I created a new expense tracking template tailored for this automated process.
